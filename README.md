# Gifty — Make Someone's Day

## 1. Judul & Deskripsi
* **Nama Produk Digital:** Gifty (Platform Pembuat Kado/Hadiah Digital Interaktif)
* **Latar Belakang Masalah:** Seringkali memberikan ucapan atau kado digital terasa monoton dan kurang personal. Gifty hadir sebagai solusi untuk membuat kartu ucapan digital interaktif yang dilengkapi animasi amplop, foto kenangan, pesan kustom, hingga integrasi pemutar lagu YouTube dalam satu tautan ringkas.
* **Target Pengguna:** Siapa saja yang ingin memberikan kejutan digital yang bermakna dan personal untuk teman, pasangan, sahabat, atau keluarga.

## 2. Teknologi yang Digunakan
* **Bahasa Pemrograman:** HTML5, CSS3, Vanilla / Native JavaScript (ES6)
* **Modul / Pustaka:** Google Fonts (Nunito & Playfair Display), Font Awesome / Icon kustom
* **Platform Publikasi:** GitHub Pages

## 3. Pemanfaatan AI (AI Usage Disclosure)
* **Alat AI yang Digunakan:** Google Gemini
* **Contoh Perintah (Prompt) Utama:** 
  > *"Tolong bantu rancangkan struktur kode HTML, CSS, dan JavaScript untuk web pembuat kado digital interaktif bernama Gifty yang memiliki fitur pilihan template, kustomisasi pesan, unggah foto, dan pemutar musik YouTube."*
* **Penyesuaian / Perbaikan Mandiri:** 
  * Menyesuaikan skema warna pastel dan tata letak *grid* galeri template agar lebih ramah pengguna (*user-friendly*).
  * Memodifikasi fungsi JavaScript untuk menangani enkripsi data kado ke dalam URL *hash* agar bisa dibagikan dengan mudah tanpa memerlukan database server.

## 4. Panduan Penggunaan
1. Buka tautan situs web aktif Gifty melalui browser: 
   👉 [https://aannaa0993-cloud.github.io/gifftie/]
2. Pilih template kado yang diinginkan dari galeri utama.
3. Klik tombol **"Make yours"** atau **"Buat hadiah"** untuk membuka lembar editor.
4. Isi nama penerima, pengirim, judul kecil, pesan ucapan, foto opsional, dan tautan lagu YouTube.
5. Klik **"Generate hadiah & link"**, lalu salin tautan unik yang dihasilkan untuk dibagikan kepada orang spesial.
