✳ gifty. — Make Someone's Day

Gifty adalah platform pembuat hadiah dan kartu ucapan digital interaktif personal yang estetik, ringan, dan dapat dibagikan dengan mudah melalui satu tautan (link).

📌 1. Judul & Deskripsi

Nama Produk Digital: Gifty

Latar Belakang Masalah: Memberikan hadiah ucapan ulang tahun atau momen spesial sering kali terbatas oleh jarak atau biaya. Aplikasi pesan singkat biasa terkesan kurang personal dan berkesan. Gifty hadir sebagai solusi digital yang memungkinkan pengguna merangkai ucapan, foto kenangan, dan lagu favorit dalam bentuk kartu interaktif (unboxing amplop) yang berkesan tanpa perlu membuat akun.

Target Pengguna: Remaja, siswa, mahasiswa, dan masyarakat umum yang ingin memberikan kejutan ucapan spesial (ulang tahun, ungkapan kasih sayang, apresiasi sahabat, dll.) secara cepat dan estetik.

🛠️ 2. Teknologi yang Digunakan

Bahasa Pemrograman: HTML5, CSS3, JavaScript (Vanilla / Native ES6)

Pustaka & Font: Google Fonts (Playfair Display & Nunito)

Teknik Utama: URL Data Encoding (Base64 & TextEncoder), Media API (FileReader API), YouTube Embed API

Platform Publikasi: GitHub Pages / Vercel / Netlify

🤖 3. Pemanfaatan AI (AI Usage Disclosure)

Alat AI yang Digunakan: Gemini / Chat GPT

Contoh Perintah (Prompt) Utama:

"Buatkan struktur antarmuka UI web modern bergaya pastel estetik untuk platform pembagi kartu ucapan digital."

"Bagaimana logika JavaScript untuk melakukan encoding data form (pesan, pengirim, penerima, foto Base64) ke Hash URL tanpa memerlukan database backend?"

"Buatkan animasi CSS 3D amplop surat yang terbuka saat diklik beserta efek partikel melayang."

Penyesuaian/Perbaikan Mandiri Peserta:

Menyesuaikan skema warna pastel, tata letak CSS, dan daya tanggap (responsiveness) tampilan mobile.

Menambahkan validasi ukuran unggah berkas foto maksimal 600 KB agar tautan URL tidak berlebihan.

Mengintegrasikan otomatisasi embed YouTube Video Player langsung ke dalam kartu hadiah digital.

Merancang variasi partikel floating emoji khusus untuk masing-masing kategori template.

🚀 4. Panduan Penggunaan

Mengunjungi Situs Web Aktif:

🔗 Tautan Web Aktif: https://aannaa0993-cloud.github.io/gifftie/

Langkah-langkah Membuat Hadiah Digital:

Buka halaman utama website Gifty.

Pilih salah satu dari 8 template kartu yang tersedia (misal: Birthday Cake, Love Letter, Bestie Certificate), lalu klik "Make yours".

Isi formulir pembuatan hadiah:

Nama Penerima & Pengirim

Judul & Pesan Ucapan

Unggah Foto (opsional, maks. 600 KB)

Link Lagu YouTube (opsional, untuk latar musik/video)

Warna Aksen pilihan.

Klik tombol "Generate hadiah & link ↗".

Klik "Salin link" dan bagikan tautan tersebut kepada orang tersayang!

Penerima cukup membuka tautan tersebut dan mengklik amplop interaktif untuk membuka kejutan.
